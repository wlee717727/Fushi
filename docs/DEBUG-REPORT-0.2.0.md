## 高：承諾的退出方式會失效

### 高 1　關掉「按鍵重複」的 Mac，長按 Esc 3 秒不會解鎖

- 位置：`Sources/Fushi/Lock/KeyboardLocker.swift:157-175`、`Sources/Fushi/Lock/PointerLocker.swift:146-162`、`Sources/Fushi/Core/EscapeHold.swift:18`
- 情境：鎖鍵盤、鎖觸控板、全鎖時，「按住滿 3 秒」是靠系統持續送出的「重複按鍵」來判斷。如果系統設定 › 鍵盤 的「按鍵重複速率」調到「關閉」，系統不會送重複按鍵，就永遠不會觸發。畫面上的圓環卻照樣跑完並顯示「正在解鎖…清潔已結束」，實際上沒有解鎖。
- 影響：只有 MacBook、沒接外接滑鼠、沒有觸控螢幕、選「C 面鎖鍵盤＋觸控板」時，只剩等時間到。
- 建議修法：第一次按下 Esc 就啟動一個 3 秒的背景計時器，放開就取消，時間到直接解鎖；不再依賴重複按鍵。補單元測試。
- 需要實機確認：我是從程式邏輯判斷的，沒有實際把按鍵重複關掉測試。

### 高 2　全鎖倒數的 3 秒內滑鼠斷線，仍然會進入全鎖

- 位置：`Sources/Fushi/App/AppModel.swift:142` (只在按開始時檢查)、`AppModel.swift:313-319` (斷線監看在鎖定後才裝上)
- 情境：按下開始後、倒數 3 秒內外接滑鼠剛好斷線 (藍牙休眠、沒電、拔掉)。鎖定開始時不會再檢查一次，而「斷線就解鎖」只在「原本有、後來沒有」時才觸發，所以不會解鎖。
- 影響：鍵盤、觸控板、觸控螢幕全鎖，卻沒有滑鼠可用，只剩長按 Esc 或等時間到。
- 建議修法：倒數結束、真正上鎖前再檢查一次；沒有外接滑鼠就不上鎖並顯示「外接滑鼠已中斷」。

## 中

### 中 1　全鎖上鎖失敗後，游標會消失

- 位置：`AppModel.swift:240-246` 與 `AppModel.swift:288-297`
- 情境：全鎖開始時攔截建立失敗 (例如倒數中權限被關掉)。程式先收拾並回到待命，但外層流程接著又執行一次「全黑時隱藏游標」，結果畫面回到主視窗、游標卻看不到，要到下一次清潔結束才恢復。
- 建議修法：上鎖失敗後立刻中止後續步驟。

### 中 2　B 面的長按 Esc 只有在「拂拭是目前使用中的 App」時才有效

- 位置：`AppModel.swift:380` (只監聽自己 App 收到的按鍵)、`Sources/Fushi/Lock/ScreenOverlayController.swift:36`
- 情境：從選單列開始、或倒數中切到別的 App，macOS 14 之後系統可能不讓拂拭搶到前景；或清潔中被 Spotlight、系統對話框搶走焦點。這時畫面是全黑的，但按鍵是打進後面那個看不到的 App，長按 Esc 也沒反應，也不會有金光提示。
- 影響：點一下畫面 (觸控板或觸控螢幕) 通常能把焦點拿回來，否則只能等時間到。盲打進看不到的 App (例如終端機) 有風險。
- 建議修法：顯示全黑後確認拂拭真的在前景，不是就再搶一次；清潔中失去前景時自動搶回。
- 需要實機確認：系統在哪些情況會拒絕，要實際試。

### 中 3　密碼欄位在輸入狀態時，鍵盤鎖不住

- 位置：`KeyboardLocker.swift:69`
- 情境：C 面鎖鍵盤時，如果前景 App 的游標正在密碼欄位 (或終端機開了「安全鍵盤輸入」)，macOS 會啟動安全輸入，所有 App 都攔不到按鍵。結果面板顯示「鍵盤已鎖定」，按鍵其實照樣打進去，長按 Esc 也偵測不到。
- 這是系統限制，無法繞過。
- 建議修法：開始前偵測安全輸入，有的話先提醒「請先離開密碼欄位」再開始；使用說明補一條常見問題。
- 需要實機確認。

### 中 4　「有外接滑鼠」的判斷太寬

- 位置：`Sources/Fushi/Lock/ExternalMouseMonitor.swift:20-49`
- 情境：只要有任何非內建、登記了滑鼠用途的裝置就算有滑鼠。羅技接收器 (滑鼠關機後接收器還插著)、帶滑鼠功能的外接鍵盤、繪圖板都會被算進去。
- 影響：(a) 沒有真的能用的滑鼠也能進全鎖；(b) 滑鼠沒電時接收器還在，「拔掉滑鼠立刻解鎖」不會觸發。
- 建議修法 (二選一，由你決定)：A. 只改說明文字，寫清楚「使用接收器的滑鼠要拔接收器」；B. 進全鎖前要求最近幾秒內真的動過外接滑鼠 (會多一句提示文字，其他畫面不變)。

### 中 5　畫面卡死時，全黑視窗會一直蓋著

- 位置：`AppModel.swift:341-350`
- 情境：鍵盤與觸控板的攔截有獨立的保險計時器，但全黑視窗要靠主程式收掉。萬一主程式卡死 (不是當掉)，B 面與全鎖的黑畫面會留著，連「強制結束」視窗都被蓋在下面。
- 建議修法：加一個背景保險：超過自動解鎖時間 5 秒，主程式還沒收掉畫面，就直接結束拂拭 (黑畫面與鎖定一起消失)。

## 實機測試清單 (請你測，我不能自己鎖你的電腦)

建議用開發版測 (自動解鎖上限 30 秒，最安全)。

1. 系統設定 › 鍵盤 把「按鍵重複速率」調到關閉 → C 面鎖鍵盤 → 長按 Esc 3 秒，看有沒有解鎖 (對應高 1)。
2. 全鎖：按開始後 3 秒倒數內關掉滑鼠電源，看會不會進入全鎖 (高 2)。
3. B 面：主視窗關掉，前景是別的 App (例如備忘錄)，從選單列開始 B 面 → 打幾個字、長按 Esc，結束後看備忘錄有沒有被打進字 (中 2)。
4. B 面清潔中按 ⌘空白鍵叫出 Spotlight，再長按 Esc (中 2)。
5. Safari 游標放在密碼欄位 → C 面鎖鍵盤 → 打字，看有沒有打進去 (中 3)。
6. 全鎖：使用接收器的滑鼠，關掉滑鼠電源但不拔接收器，看會不會解鎖 (中 4)。
7. C 面鎖觸控板中闔上螢幕再打開，在登入畫面確認能輸入密碼；超過時間後觸控板恢復。
8. B 面清潔中插上、拔掉外接螢幕，確認每個螢幕都是黑的、結束後游標與 Dock 正常。
9. B 面清潔中用觸控板做三指、四指手勢與熱點角落，看會不會跳出別的畫面。
10. 清潔中到系統設定把「輔助使用」關掉 (C 面)，確認鍵盤恢復、面板最後會自己消失。
11. 主視窗：淺色與深色、最大化、左右分屏、拉到最窄再拉大；Dock 放左側與右側時倒數面板位置。
