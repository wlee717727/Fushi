# 拂拭 0.2.1 實機測試清單

這些情況只能在真的電腦上測 (程式審查看不出系統實際行為)。每項打勾或寫下看到什麼即可。
全部都有「時間到自動解鎖」保底，建議自動解鎖時間調到 1 分鐘再測。

## 一定要測 (跟「一定能退出」直接相關)

- [ ] 1. **按鍵重複關閉**：系統設定 › 鍵盤，把「按鍵重複速率」拉到「關閉」→ C 面只鎖鍵盤 → 長按 Esc 3 秒，應該解鎖。測完記得把按鍵重複改回來。
- [ ] 2. **權限中途關閉**：C 面只鎖鍵盤 → 用觸控板到系統設定 › 隱私權與安全性 › 輔助使用，把「拂拭」關掉 → 約 2 秒內鍵盤恢復、跳出說明並打開權限頁。測完再打開。
- [ ] 3. **睡眠喚醒**：C 面只鎖鍵盤 → 闔上螢幕 10 秒再打開 → 解鎖登入後，不應該跳出「權限被關閉」；時間到照常解鎖。
- [ ] 4. **全鎖倒數中滑鼠斷線**：關掉主視窗 → 從選單列開始全鎖 → 倒數 3 秒內關掉滑鼠電源 → 不應該上鎖，主視窗會跳出「外接滑鼠已經中斷」。
- [ ] 5. **長按 Esc 時前景有對話框**：開一個有「取消」按鈕的對話框 (例如備忘錄的「另存新檔」) → C 面鎖鍵盤 → 長按 Esc 解鎖 → 對話框不應該被關掉；1.5 秒後再按 Esc 應該正常。

## 建議測

- [ ] 6. **密碼欄位**：Safari 游標停在任何密碼欄位 → C 面鎖鍵盤 → 按開始，應該跳出「安全輸入」說明、不會開始。
- [ ] 7. **B 面從選單列開始**：主視窗關掉、備忘錄在前景 → 從選單列開始 B 面 → 打幾個字、長按 Esc → 結束後備忘錄不應該被打進字。
- [ ] 8. **B 面叫出 Spotlight**：B 面清潔中按 ⌘空白鍵 → 畫面應該維持全黑，長按 Esc 仍能結束。
- [ ] 9. **全螢幕 App**：讓某個 App 全螢幕 → 開始 B 面再結束；開始 C 面再結束 → 選單列與 Dock 的自動隱藏都正常。
- [ ] 10. **外接螢幕**：B 面清潔中插上、拔掉外接螢幕 → 每個螢幕都是黑的，結束後游標與 Dock 正常。
- [ ] 11. **B 面遇到系統對話框**：B 面清潔中讓系統跳出密碼對話框 (或鎖定螢幕再解鎖) → 畫面不應該一直閃爍。
- [ ] 12. **接收器滑鼠** (有的話)：全鎖 → 只關滑鼠電源、不拔接收器 → 不會解鎖 (這是已知限制，說明裡有寫)；拔掉接收器 → 立刻解鎖。
- [ ] 13. **主視窗版面**：淺色與深色、最大化、左右分屏、拉到最窄再拉大；Dock 放左側與右側時，倒數面板對齊插畫框。

## 看到問題時

截圖給原本的對話，並說是第幾項。需要診斷紀錄時：按住 ⌥ 打開「輔助說明」選單 → 「拷貝診斷資訊」，貼給 AI。
