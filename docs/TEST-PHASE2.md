# 實機測試：鎖觸控板、全鎖、緊急退出

每一項大約 1 分鐘。建議先到「拂拭 › 設定」(⌘,) 把自動解鎖時間調成 1 分鐘，萬一出狀況最多等 1 分鐘。

## 1. C 面：只鎖觸控板
1. 左邊選「C 面清潔」，關掉「鍵盤」、打開「觸控板」，按「開始清潔」。
2. 倒數 3 秒後：
   - 摸觸控板 (移動、點按、兩指捲動、三指滑動)：**游標和畫面都不應該動**。
   - 動外接滑鼠：**應該正常**。
   - 用手指點觸控螢幕：**應該正常**。
   - 打字：**應該正常** (鍵盤沒鎖)。
3. 用滑鼠或觸控螢幕按住上方面板的「按住 2 秒結束清潔」→ 應該解鎖。

## 2. C 面：鍵盤＋觸控板
1. 「鍵盤」「觸控板」都打開，開始。
2. 打字、按亮度音量鍵、摸觸控板都沒反應；滑鼠與觸控螢幕正常。
3. **長按 Esc 3 秒** → 應該立刻全部解鎖。

## 3. 全鎖
1. 確認外接滑鼠已連線 (全鎖頁顯示「已連接」)，按「開始清潔」。
2. 螢幕全黑後：打字、觸控板、觸控螢幕都沒反應。
3. 動一下滑鼠 → 出現控制面板 → 用滑鼠按住「結束清潔」2 秒 → 解鎖。
4. 再開始一次全鎖，這次**關掉滑鼠電源或拔掉接收器** → 應該立刻解鎖。

## 有問題時
- 「輔助說明」選單：按住 ⌥ 會出現「拷貝診斷資訊」，複製後貼給開發者。
- 一定能退出的方法：長按 Esc 3 秒、等自動解鎖時間到、選單列的拂拭圖示選「結束清潔」。
