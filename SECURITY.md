# Security Policy / 安全性

Fushi intercepts keyboard and trackpad input while you clean, so security and "you can always get out" matter.
拂拭在清潔期間會攔截鍵盤與觸控板輸入，安全性與「一定解得開」非常重要。

## Reporting a vulnerability / 回報漏洞

Please **do not open a public issue** for security problems. Use GitHub's private reporting instead:
**Security › Report a vulnerability** on this repository.
安全問題請**不要公開開 issue**，請用本專案的 **Security › Report a vulnerability** 私下回報。

Examples / 例如：
- A way to stay locked after the auto-unlock time, or after holding Esc for 3 seconds / 時間到或長按 Esc 3 秒後仍然解不開
- Fushi recording or leaking what you type / 拂拭記錄或外洩輸入內容
- Anything that lets another process abuse Fushi's Accessibility permission / 其他程式可以濫用拂拭的輔助使用權限

## If you are locked right now / 現在被鎖住了

Hold **Esc for 3 seconds**, wait for the auto-unlock, unplug the external mouse (Full Lock), or turn off Fushi in System Settings › Privacy & Security › Accessibility. As a last resort, hold the power button to shut down.
長按 **Esc 3 秒**、等時間到、拔掉外接滑鼠 (全部鎖定)，或到「系統設定 › 隱私權與安全性 › 輔助使用」關掉拂拭。真的不行就按住電源鍵關機。

## Supported versions / 支援版本

Only the latest release receives fixes. / 只修正最新版本。
